# Pizza Légende — nouveau site

Refonte responsive du site Pizza Légende, prête à être hébergée sur GitHub Pages, Vercel, Netlify ou tout hébergeur statique.

## Installation

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
```

Le dossier `dist/` contient le site compilé. Les coordonnées, horaires, points de vente et liens sociaux sont centralisés dans `src/main.jsx`.

## Déploiement GitHub

1. Créez un nouveau dépôt GitHub.
2. Ajoutez tous les fichiers de ce dossier au dépôt.
3. Pour Vercel ou Netlify, importez le dépôt : la commande de build est `npm run build` et le dossier publié est `dist`.

Les photos et le logo proviennent du site Pizza Légende fourni comme source par son propriétaire.
